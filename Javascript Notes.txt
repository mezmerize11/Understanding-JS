** LESSON 4** Variables 
Variables is a container
The word keyword "Let" creates a variable --> then you give the Let a name such as. ex (let variablename = input string or text)

variable name restrictions/rules
1. You must not use reserved words such as:
	Reserved Words or keywords (let )
2. Must not begin in a number.
3. Must not begin with special characters
	ex. let $name = ;
	ex. let _name = ;

Semicolon ';' is an end to an instruction. 

Reassigning values --> when reassigning a value, not necessary to put a keyword such as the word let

onclick inside a button javascript reads it.

using typeof within a code, lets us know what type of data it holds such. "strings, number"

Best Practices for naming convensions a variable.
	1. Dontaddspacesonthevarible
	2. camelCase - combining words to form a variable with the second word starting in uppercase. Standard naming convention in JS
	3. PascalCase - setting combined words starting with an Uppercase letter.
	4. kebab-case - naming a variable with all lowercase and combining two words by a hyphen.
		--> often used in html and css.
	5. snake_case - combining two words to name a variable by using a underscore "_".
		--> used in other programming languages.
